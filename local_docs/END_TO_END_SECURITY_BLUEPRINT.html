2. Operator's Emergency Incident Runbook (समस्या निवारण फील्ड गाइड)

If any incident, block, or error occurs on production, follow these exact 7 field runbooks. You do not need an AI assistant; each scenario includes direct terminal commands and Redis keys.

🚨 Scenario 1: Search returns 503 "SERVER_BUSY"

Cause: Request user-agent matched bot regex (e.g. curl, postman, python) or OpenWebNinja hit upstream downtime.
Fix: Check line 167 of src/app/api/search/route.js. Ensure testing requests pass a standard browser header (User-Agent: Mozilla/5.0...). If OpenWeb is down, check OPENWEBNINJA_API_KEY quota on OpenWebNinja portal.

⏳ Scenario 2: Real User hits 429 "Quota Exceeded"

Cause: User exceeded their 10 daily live search calls or 30 IP calls.
How to Reset Immediately:
node -e "const {redis}=require('./src/services/redis'); redis.del('quota:unified_api:HASH:DAY')"
Or tell the user to view cached deals (free & unlimited) or sign in for fresh daily quota.

🛡️ Scenario 3: Real User IP got Accidentally Throttled

Cause: Passive Burst Tripwire flagged the IP after rapid queries (>4 in 2.5s).
How to Remove Throttle in 1-Click:
Open /admin ➔ Security Radar Tab ➔ Click "Clear Throttle" next to their IP.
Or via terminal: redis.del('security:throttle:' + userIp).

👗 Scenario 4: Virtual Try-On Fails or Times Out

Cause: Modal GPU serverless endpoint is cold-starting (>15s) or image >10MB.
How to Verify:
1. Verify MODAL_VTON_ENDPOINT in .env.local.
2. Check if user credit was deducted: The atomic Lua script automatically releases slots on failure (releaseVtonFreeSlot), so user credits are never lost!

🧹 Scenario 5: Stale Prices or Need to Flush Redis Cache

Cause: You updated prices or want to clear cached items immediately.
How to Flush in 1-Click:
Open /admin ➔ Cache Manager Tab ➔ Click "Flush Search Cache".
This only deletes cache:search:* keys without touching user accounts or permanent ledgers!

🔒 Scenario 6: Admin Panel redirects to Home (401)

Cause: The logged-in Clerk User ID does not match ADMIN_USER_IDS.
Fix: Check Clerk Dashboard for your user ID (e.g. user_3JGg_MnXc5O3td). Ensure ADMIN_USER_IDS=user_3JGg_MnXc5O3td is set in Vercel Environment Variables.

🔗 Scenario 7: Broken Product Link Reported by User

Cause: Merchant changed product URL or out of stock.
Fix: Open /admin ➔ Helpdesk Tickets Tab. Review user's reported URL. Our Universal Redirect Engine automatically falls back to clean merchant search if PDP is expired.
